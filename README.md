# RGB---
该软件实现了将文件加密成rbg图片，使用加密后的图片本地还原软件，用于内网渗透传输数据，将加密后的图片上传到服务器，在网站浏览页面下载图片，实现隐匿传输数据功能

该工具为ai制作，感谢ai。


RGB 像素隐写工具 · 成品包
========================================

这个包里是两个平台的成品，都是最新构建，功能完全相同。
网页版与命令行版共用同一份编解码算法，互相兼容：
Windows 版加密的图片，Linux 版能解；反之亦然。

【Windows 版】  Windows版\
  双击「RGB像素隐写工具.exe」即可使用（需 .NET Framework 4.x，Win10/11 自带）。
  程序会在本机启动一个只监听 127.0.0.1 的服务并自动打开浏览器，
  浏览器没自动打开时点窗口里的「在浏览器中打开工具」，关闭该窗口即停止服务。

    · 图形界面：页面左侧加密、右侧解密，保存时可自定义位置与文件名
    · 命令行版\：encrypt.cmd / decrypt.cmd / 批量加密.cmd / 批量解密.cmd
      需要 Node.js，用法见 Windows版\命令行版\使用说明.md

【Linux 版】  Linux版\
  rgb-stego-linux.tar.gz   安装包，传到 Linux 上使用：
      tar xzf rgb-stego-linux.tar.gz
      cd rgb-stego
      sh install.sh          # 安装：命令行入口 + 应用菜单项（只写用户目录，无需 root）
      ./rgb-stego.sh         # 或直接启动图形界面

  rgb-stego\               同一份内容解压好的，方便直接查看
  需要 Node.js 18 或更高版本。详细说明见 Linux版\rgb-stego\使用说明.md

  注意：Windows 文件系统没有 Unix 权限位，上面这份解压副本的 .sh / .mjs
        没有可执行位；在 Linux 上用 tar.gz 解压则权限位完好。若只能用解压副本，
        补一句：chmod +x *.sh *.mjs

【怎么用（两个平台都一样）】
  加密：输入文字或选择文件 → 选像素块大小 → 生成图片 → 保存 PNG
  解密：选择或拖入加密图片 → 自动还原出原始数据 → 保存
  每个字节对应图片里的一个像素块：高 3 位 → R，中 3 位 → G，低 2 位 → B，
  共 256 种互不重复的颜色，完整覆盖 ASCII 表 0–127 与全部字节 0–255。
  例：a = 97 = 01100001 → 色码 (3,0,1) → rgb(112,16,96)

【注意】
  · 加密后的 PNG 必须原样保存：截图、转 JPG、有损压缩都会导致无法还原。
  · 需要经聊天软件传输时，请用 4×4 及以上的像素块，并以「文件」方式发送原图。
  · 本工具是隐写（把数据藏进图片），不是加密算法；需要保密请先加密明文再编码。
